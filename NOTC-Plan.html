3
План разработки

Фаза 1 — MVP (0–2 мес)

  • PIN авторизация водитель/владелец
  • Pre/Post Trip инспекция (DOT)
  • Фото одометра + OCR
  • Учёт расходов и чеков
  • Отчёты для владельца
  • Тест на мобильном (iOS/Android)
  • Подпись водителя на инспекции
  • PWA — установка без App Store
  • Деплой Vercel + PostgreSQL
  • HTTPS, rate limiting, CSRF защита
📋 Модуль: Заказчики (Clients) — водитель выбирает заказчика при старте рейса; все трипы, расходы и фото автоматически привязываются к нему.
Для владельца: создание/редактирование заказчиков · отчёты по каждому · фильтрация расходов и инспекций по клиенту.
Для водителя: список активных заказчиков на экране «Start Trip» · один клик — данные идут в нужный аккаунт.
СущностьПоляПривязка
Clientname, contact, rate ($/mile), notes→ Trip, Expense, Report
Trip+ client_id (FK)при старте рейса
Expense / Фотонаследуют client через tripавтоматически
Reportфильтр по client_idOwner dashboard

Фаза 2 — Малый флот (2–4 мес)

  • Мульти-водители и мульти-машины
  • Управление заказчиками — CRUD для Admin, выбор при старте рейса
  • Отчёт по заказчику — расходы, пробег, чеки за период
  • GPS трекинг (Geolocation API)
  • HOS — Hours of Service (базовый)
  • IFTA — топливный налог по штатам
  • Email/SMS уведомления
  • Испанский язык (i18n)
  • Offline режим для инспекций

Фаза 3 — Средний флот (4–8 мес)

  • Dispatch — назначение рейсов
  • Maintenance — планирование ТО
  • Аналитика расхода топлива
  • Биллинг по заказчикам — автогенерация инвойса (PDF) за период
  • Роли: Owner / Manager / Driver / Mechanic
  • Public API для интеграций
  • AI агенты: автоотчёты, аномалии

Фаза 4 — Enterprise (8–12 мес)

  • SSO / корпоративный вход (SAML)
  • White-label версия
  • OBD-II интеграция
  • Нативные iOS и Android приложения
  • Мультиязычность (испанский, португальский)
  • BI дашборд и расширенная аналитика

7
Безопасность
Важно: DVIR/HOS/IFTA — юр. документы. Утечка = штрафы DOT + иски. Безопасность обязательна.

Уровень 1 — Базовый (Фаза 1)

🔒HTTPS/TLS 1.3Vercel авто-SSL, HTTP→HTTPS редирект
🛡️Rate Limiting5 попыток PIN / 15 мин, блок IP на 1 час
🍪СессииHttpOnly, Secure, SameSite=Strict, выход 8ч
🔐PIN хэшbcrypt salt=12, не восстановить при утечке

Уровень 2 — Приложение (Фаза 2)

🚫SQL InjectionDrizzle ORM параметризованные запросы + Zod
🌐XSSReact экранирует HTML, CSP заголовки
🔑API AuthКаждый endpoint проверяет сессию, RLS в БД
📁ФайлыMIME проверка, 10MB лимит, private R2 bucket

Уровень 3 — Enterprise (Фаза 3–4)

📋Audit LogКто/что/когда/IP — неизменяемый лог
🔍PentestOWASP ZAP авто + ручной перед Enterprise
🏥SOC 2Сертификация при 50+ B2B клиентах
💾БэкапЕжедневный зашифр. + 7 дней point-in-time
